# 여행 취향 데이터

Qwen 학습기는 [preference-v2.jsonl](generated/preference-v2.jsonl)의 한 줄을 사례 하나로 읽습니다. 규칙으로 만든 합성 사례 205개 중 `train` 168개로 학습하고 `dev` 11개로 체크포인트를 선택합니다. `test` 26개는 최종 비교용입니다. [분할과 해시](generated/preference-v2.manifest.json), [학습 설정](../configs/train.json)에서 같은 버전을 확인할 수 있습니다.

## 사람이 작성할 때

2026-11-15 추가 학습에 사용한 [JSONL](generated/preference-v2-review.jsonl)은 기존 사례의 분할을 보존하고 새 합성 예시 12건을 학습 분할에만 추가합니다. 6개 예시 묶음은 조건부 방문, 의도 변경, 횟수와 적용 범위, 당사자 구분처럼 취향 분석에서 혼동하기 쉬운 표현을 다룹니다. 전체 분할과 파일 지문은 [추가 학습 데이터 기록](generated/preference-v2-review.manifest.json)에 있습니다. 실제 평가 양식과 사용자 점수는 로컬 검토본에 보관합니다.

[취향 데이터 양식](preference-form.csv)은 첫 행이 열 이름이고 둘째 행이 실제 학습 사례입니다. 새 사례는 다음 행에 번호, 여행 요청 원문, 기대 해석을 적습니다. 직접 평가할 사례라면 용도에 ‘사람 평가’를 적고, 모델을 실행한 뒤에만 AI 결합 해석과 점수를 채웁니다. 원문에 쓰지 않은 기대는 ‘내 코멘트’에 구분해서 적습니다. 기존 사례를 옮겼다면 ‘출처 번호’에 이전 번호를 보존합니다.

CSV는 사람이 읽고 작성하는 양식입니다. JSONL은 원문, 여행방 설정, 구조화된 정답, 분할, 출처를 보존합니다. 모델은 정답의 취향 조건, 확정 일정, 보류 항목을 예측하도록 학습합니다. 점수나 자유 서술 의견은 학습기에 자동으로 들어가지 않습니다. 별도 사람 평가셋의 형식과 이용 범위는 [평가 자료 안내](human/README.md)를 따릅니다.

## 학습 데이터 검증

AI 저장소 루트의 프로젝트 환경에서 실행합니다.

```sh
python -m training.validate_dataset --path data/generated/preference-v2.jsonl
```

현재 데이터의 SHA-256은 `0019cde72115fb7c6ba950b8928ba83f30e00da904407073d787d0a539d0d32f`입니다. 제출 이후 별도 실험을 할 때는 학습 설정을 복사하고 `output_dir`에 새 경로를 지정합니다. 데이터도 바뀌면 새 파일 경로와 해시를 기록합니다. 심사용 서비스는 제출 버전의 어댑터를 계속 읽도록 설정합니다.
