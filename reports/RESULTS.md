# Gemini–Qwen 고도화 실행 결과 — 2026-11-14

Qwen3.5-4B의 실제 LoRA 학습, 두 제공자 병렬 분석, FE/BE 개인 조건 왕복, 단체 인수 자료와 제출 패키지 준비를 구현했다. 결과는 **연구·개발용**이다. 합성 시험만으로 사용자 정확도나 출시 준비를 입증하지 않는다.

Gemini를 학습시킨 것이 아니며 두 모델을 스태킹 학습한 것도 아니다. Qwen에 지도 미세조정한 별도 adapter를 만들고, 추론 때 Gemini와 독립 분석한 뒤 규칙으로 대조한다. 합성 정답은 규칙으로 작성·검증했으며 Gemini 교사 정답이나 사람 검수 자료로 표시하지 않는다.

## 고정 test 비교

같은 26개 입력·9개 family를 사용했다. v2 정답은 원자 조건 24개, required 또는 limit 조건 7개, 예약 2개다. test를 checkpoint 선택이나 이후 프롬프트 수정에 사용하지 않았다.

점수는 target 표현·부정·중요도·범위·횟수·value/unit·근사 여부가 일치하는 **엄격한 tuple 일치 지표**다. 같은 의미의 다른 표현도 불일치가 될 수 있다. 값은 사람의 정확도가 아니다. v1은 표현 가능한 정보량이 달라 atomic F1에서 제외했다. 유효 출력은 결합된 계약·근거 검사 결과이며 JSON 문법만의 성공률과 의미 정확도를 별도로 입증한 수치가 아니다.

조합은 두 정상 응답의 일치 조건만 적용하므로 정밀도가 높아지는 대신 조건을 많이 보류했다. 25개 성공 중 23개는 두 제공자가 모두 정상, 2개는 단일 제공자 fallback이다. 1개는 전체 실패다. 불일치·보류도 누락 평가에서 면제하지 않았다. 예약의 엄격한 일치는 기반 0/2, 학습 Qwen 2/2, Gemini v2 1/2, 조합 1/2다.

최초 외부 평가에서는 연속 요청 중 이용 불가 응답이 많았다. 이후 호출 시작 간격을 5초로 두고 같은 시험을 다시 실행했다. 최초 결과는 장애 진단 기록으로 보존하고 위 비교에는 사용하지 않았다. 재실행에서도 새 프롬프트나 학습을 적용하지 않았다. 호출 시간은 모델 초기화와 요청 간 대기 시간을 제외하며, local/HTTP/API의 실행 경로가 달라 순수 모델 속도 비교가 아니다.

수치·출처 파일 SHA는 [EVALUATION_SUMMARY.json](EVALUATION_SUMMARY.json)에 있다. JSON/CSV 원자료는 제출 ZIP의 evaluation/reports에 포함한다.

## 기능 검증과 발견한 실패

- FE: 같은 화면에서 원자 조건·횟수·범위 직접 수정, 원문 근거, stale 처리, 저장·직접 확정, 새로고침 복원을 연결했다. 1440/768/390px와 키보드·오류 UI를 확인했다. 브라우저 검수는 합성 SQLite·모의 모델 환경이다.
- BE: v1 호환, v2 영수증의 기기·본인·버전 검증, 직접 수정 출처, 현재 확정 조건 캡처를 구현했다. 단체 인수에는 개인 필수 조건·동등한 1인 지지·충돌과 unresolved 코드만 전달하며 원문 근거와 실제 회원 ID를 공개하지 않는다.
- 실제 두 모델 + BE: 공통 fixture의 숙소/고정일정 텍스트 기본값을 명시적으로 지운 조건에서, 개발용 초밥 입력의 조회→원문 저장→실제 두 모델 분석→영수증 저장→확정→조회가 모두 HTTP 200이었다. 두 제공자 모두 사용했고 degraded=false, 조건 1개와 저장 출처가 그대로 복원됐다. [검수 기록](live/stack-acceptance-clean-context.json).
- 공통 fixture의 “조용한 숙소” 희망 문구를 남긴 시험은 Gemini가 이를 개인 조건/예약처럼 출력해 근거 검사에서 거절됐다. strict 두 모델 검수는 HTTP 503으로 실패했다. [실패 기록](live/stack-acceptance.json), [진단](live/stack-food-diagnostic.json). 이 제한을 성공 사례로 합치지 않는다. 기본 비엄격 모드는 정상 제공자만 사용하고 degraded를 표시할 수 있다.
- 자동 검사는 AI/BE/FE 단위·SQLite 검사이며 운영 MySQL·실제 기기 쿠키 인증·실제 모델을 연결한 브라우저 전체 인수와 구분한다. 최종 검사 수는 전달 기록에 기재한다.

## 아직 입증하지 않은 것

test에는 gold unresolved 사례가 **0개**여서 이 수치로 모호한 문장 처리 능력을 입증할 수 없다. 26행도 9개 family의 반복 구조를 포함하므로 독립적인 26명 사용자 시험이 아니다. 약한 합성 정답과 엄격한 표현 일치의 한계가 있다. 사람이 독립 작성·검수한 [평가 자료](../data/human/README.md)가 필요하다.

최신 원자 조건의 정확한 방문 횟수·날짜별 제약을 장소 선택·TOPTW·2-opt/relocate가 모두 반영하는 부분은 일정 담당자의 후속 연동이다. 이번 내부 인수 자료 생성만으로 경로 제약 준수를 주장하지 않는다.

Docker 설정과 고정 CUDA 이미지 digest는 준비했지만 WSL 목록 조회 시간 초과·Docker engine pipe 부재로 빌드/실행을 검증하지 못했다. 실제 학습·서빙 검수는 Windows CUDA에서 수행했다. Docker 데이터 초기화·배포·공용 DB 변경은 하지 않았다. 운영 배포·사람 평가·공개 adapter 업로드도 완료 상태가 아니다.
